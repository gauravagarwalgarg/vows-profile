# Biodata Generator

Welcome to the documentation for the **VowsProfile** Biodata Generator project.

## Overview
VowsProfile is a client-side web application that allows users to rapidly input their personal, professional, and family details to generate a stunning, print-ready, A4-sized Biodata profile.

This project combines traditional aesthetics with modern web technologies, offering an intuitive UI and a high-quality PDF export capability.

## Live Application
**[Launch VowsProfile →](https://gauravagarwalgarg.github.io/VowsProfile/)**

## Key Features
- **Real-time preview** with reactive data binding
- **300 DPI PDF export** with pixel-perfect rendering
- **Multi-format export** — PDF, JPG, PNG, DOCX
- **Dynamic entries** — up to 3 degrees, 4 profile links, 4 siblings, 3 phone numbers
- **Auto-fit scaling** — content automatically adjusts font size to fit A4 page
- **LocalStorage auto-save** — progress persists across sessions
- **Zero server upload** — all processing happens in your browser
