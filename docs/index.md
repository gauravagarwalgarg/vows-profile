# Biodata Generator

Welcome to the documentation for the Biodata Generator project.

## Overview
The Biodata Generator is a client-side web application that allows users to rapidly input their personal, professional, and family details to generate a stunning, print-ready, A4-sized Biodata profile. 

This project aims to combine traditional aesthetics with modern web technologies, offering an intuitive UI and a high-quality PDF export capability.
